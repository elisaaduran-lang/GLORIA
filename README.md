# GLÓRIA — É O NO

Web experimental/editorial para Gloria, anís con mosto.

## Stack
- React
- Vite
- GSAP + ScrollTrigger
- Lenis
- CSS

## Ejecutar en local

```bash
npm install
npm run dev
```

Después abre la dirección local que muestre Vite.

## Publicar en GitHub Pages

1. Crea un repositorio llamado `gloria-web`.
2. Sube todos los archivos de esta carpeta al repositorio.
3. Ve a **Settings → Pages**.
4. En **Source**, selecciona **GitHub Actions**.
5. Haz push a `main`.
6. El workflow incluido en `.github/workflows/deploy.yml` construirá y publicará la web.

Las dos imágenes actuales de la botella ya están incluidas en `public/images/`.
